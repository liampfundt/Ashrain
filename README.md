# Ashrain

`Note: Ashrain is far from finished and is still unusable for the biggest part.`

Ashrain is a easy-to-use program that can help you create macOS machines in Oracle VirtualBox.
The range of macOS operating systems goes from *Mac OS X Lion 10.7* all the way to *macOS Sonoma 14* and more to come.

You can check out the screenshots of Ashrain in the `assets/` folder.
